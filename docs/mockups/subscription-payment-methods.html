Can a new workspace pay for a plan?

    Send-money accounts

    Workspaces send the invoice amount here and submit the transaction ID. An operator confirms it in Invoices.

    Critical · 2 operators

    Changing where money goes needs a reason and a second operator's approval of the exact value. Every change is in the audit log.

    Online checkout

    CommerceOS's own merchant accounts. Credentials stay in the server environment and are never shown here.

    How to connect a gateway
    Set these on the server (Render → Environment), then redeploy. Use sandbox mode until the merchant account is approved.

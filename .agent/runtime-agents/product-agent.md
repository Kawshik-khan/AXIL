
# Product Intelligence Agent Skill

## Operating Procedures

1. **Product Performance Analytics**:
   - Analyze sales velocity, gross margin per SKU, return rate, and conversion efficiency.
   - Flag products with high return rates ($> 20\%$) for quality inspection.

2. **Catalog Enrichment**:
   - Extract structured attributes from raw product descriptions (e.g. Fabric: "100% Organic Cotton", Sleeve: "Full Sleeve", Fit: "Slim Fit").
   - Suggest appropriate category hierarchy.

3. **Comparison & Cross-Sell**:
   - Identify complementary items for bundling (e.g. Kurti + Palazzo, Shoes + Socks).

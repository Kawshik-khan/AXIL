
# Analytics Agent Skill

## Operating Procedures

1. **Deterministic KPI Calculations**:
   - **Average Order Value (AOV)**: $\text{Total Revenue} / \text{Total Completed Orders}$.
   - **Return-to-Origin (RTO) Rate**: $\text{Returned Orders} / \text{Total Shipped Orders} \times 100\%$.
   - **AI Automation Rate**: $\text{Unassisted Completed Conversations} / \text{Total Inbound Inquiries} \times 100\%$.

2. **Channel Performance**:
   - Attribute sales and conversion rates across Facebook Messenger, Instagram DMs, WhatsApp, and Website.

3. **Report Generation**:
   - Generate structured daily, weekly, and monthly operational summaries for the executive Bento dashboard.

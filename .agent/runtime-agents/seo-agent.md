
# SEO Agent Skill

## Operating Procedures

1. **Title & Meta Tag Generation**:
   - Generate SEO-optimized titles ($\le 60$ chars) and meta descriptions ($\le 155$ chars) for products and categories.
   - Include primary search keywords (e.g. "Panjabi", "Cotton Saree", "Sneakers Bangladesh").

2. **Structured Data Markup**:
   - Suggest JSON-LD `Product`, `Offer`, and `AggregateRating` schemas for web store pages.

3. **Content Audits**:
   - Detect missing image alt tags, duplicate product descriptions, and broken links.
   - Present recommendations for operator approval; do not silently rewrite public pages.
